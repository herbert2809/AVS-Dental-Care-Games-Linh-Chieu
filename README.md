# Dental Care Games – Linh Chieu Open House

Classroom games for the AVS Open House lesson "Unit 5: Dental Care" (Amazing Science 1, Grade 1).
The games are made for one shared screen and four teams: Red, Blue, Green and Yellow.
This version follows the feedback of 20/10/2026: no on-screen scores (the teacher keeps points on the board), and the teacher models the first turn of Games 1, 2, 4 and 5.

## Games

| File | Game | Lesson stage |
| --- | --- | --- |
| `index.html` | Home page with all games | |
| `game1-good-or-bad.html` | Good or Bad for Your Teeth? Five numbered tiles: the teacher models one, then one for each team | Lead-in |
| `game2-listen-and-tap.html` | Listen and Tap. Five questions with spoken audio: one teacher model, then one for each team | Presentation |
| `game3-happy-or-sad-tooth.html` | Happy Tooth or Sad Tooth? Eight cards to sort | Practice |
| `game4-pop-and-say.html` | Pop and Say. A teacher model round (eat candy), then eight pictures under bubbles | Practice |
| `game5-lucky-tooth.html` | Lucky Tooth. Five teeth: tooth T for the teacher, then one for each team; every tooth shows a sentence starter | Production |
| `timer.html` | Countdown timer, set to 3 minutes | Production |

## How to use

- Online: open the GitHub Pages link of this repository.
- Offline: download the HTML files and open `index.html` in Chrome or Edge. Each file works without internet.
- Game 2 reads each phrase aloud (browser voice). Tap "Listen" or the ear to hear it again. Turn the speakers on.

## Editing

The files in the main folder are built from `src/`. After changing anything in `src/`, run `python3 build.py`.
All pictures are original drawings made for these games.
